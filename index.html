📄

Selamat Datang di MagangHub Screener!

Tool ini akan mencocokkan CV kamu dengan 200+ lowongan magang dari MagangHub Kemnaker RI secara otomatis.

1
Siapkan file CV

Buat file cv-profile.json berdasarkan template yang tersedia. Lihat file data/cv-template.json sebagai contoh format.

2
Upload CV kamu

Klik tombol di bawah untuk mengupload file JSON CV kamu.

3
Jalankan Screening

Klik "Jalankan Screening" di Dashboard dan lihat lowongan mana yang paling cocok!

💡 Lihat file data/cv-template.json untuk contoh format CV yang benar.
